# Newsreader

Newsreader v26 is bundled through `@fontsource-variable/newsreader` as Disco's display serif. Vite emits the normal and italic variable WOFF2 files with the application, so the font has no runtime network dependency.

- Source: https://github.com/productiontype/Newsreader
