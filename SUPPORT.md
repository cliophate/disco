# Support

Disco is community-supported software provided without warranty or a service-level agreement.

## Questions and Troubleshooting

Use GitHub Discussions if enabled. Otherwise, open a GitHub issue with the appropriate template after checking the README, deployment guide, upgrading guide, existing issues, and logs.

Include the Disco version or commit, operating system, deployment method, PHP/PostgreSQL/Redis versions, exact command, expected and actual behavior, and sanitized error output. Replace credentials, hostnames, IP addresses, email addresses, machine identifiers, library UUIDs, media paths, and listening data before posting.

Support is limited to Disco itself. General administration of Plex, reverse proxies, TLS, Docker, PostgreSQL, Redis, DNS, firewalls, and third-party provider accounts is outside project support, though reproducible Disco integration bugs are in scope.

Only single-owner deployments are supported. Multi-user use, public registration, multi-tenancy, and directly internet-exposed origins are unsupported.

## Security Reports

Do not use public support channels for vulnerabilities. Follow [`SECURITY.md`](SECURITY.md).
